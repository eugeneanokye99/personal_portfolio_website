I've spent most of my time building backend systems in Java and Spring Boot — APIs, scheduling engines, auth flows, the kind of infrastructure that's invisible when it works and very visible when it doesn't.

This blog is where I'll write about that work in more depth than a project card allows: the tradeoffs behind a design decision, a bug that taught me something, or a pattern I keep reaching for.

Expect posts on:

- API design and resilience
- Spring Boot and the JVM ecosystem
- Databases, migrations, and the mistakes that come with them
- Systems design tradeoffs from real projects

If something here is wrong or you'd argue it differently, [reach out](https://www.linkedin.com/in/edanokye) — I'd rather be corrected than confidently wrong in public.
